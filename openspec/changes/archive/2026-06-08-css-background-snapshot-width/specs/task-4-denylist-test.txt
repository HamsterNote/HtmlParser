## Denylist Properties (explicitly excluded from capture)
These properties must NEVER appear in captured styles:
1. transition - animation timing, not visual snapshot
2. animation - animation effects, not visual snapshot
3. cursor - interaction hint, not visual
4. user-select - interaction behavior, not visual
5. will-change - performance hint, not visual
6. -internal-* - vendor-internal properties

## Out-of-scope
Pseudo-elements (::before, ::after) are explicitly out of scope because
TreeWalker only traverses real DOM element nodes.
